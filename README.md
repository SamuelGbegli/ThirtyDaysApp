# ThirtyDaysApp

## Introduction
This is an Android application that shows a scrollable stack of 30 cards relating to a different programming language. This is based on the 30 Days project on the Android developers website ([viewable here](https://developer.android.com/codelabs/basic-android-kotlin-compose-30-days#0)).
The application can be built and run using Android Studio.

## Notes
There is an alternate version where the user can press on a programming language card and view information about one language. To view that, please switch to the branch called "grid-and-view".

## Cloning the project
To clone the project, make sure you are on either the "initial-version" or "grid-and-view" branch, as these contains working versions of the application.

## Code samples
As part of the project's requirements, there are screenshots of short programs written in the languages featured. The source code for each program is included in the repository and can be found in the folder "Code samples".
