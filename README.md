# ThirtyDaysApp

## Introduction
This is an Android application that shows a scrollable grid of 30 cards that can be tapped to view information about a programming language. This is based on the 30 Days project on the Android developers website ([viewable here](https://developer.android.com/codelabs/basic-android-kotlin-compose-30-days#0)).
The application can be built and run using Android Studio.

## Notes
There is a version of the application that shows all the information in a single, scrollable column instead of using a grid and views. To view that version, please go to the "initial-version" branch.

## Cloning the project
To clone the project, make sure you are on the "initial-version" branch, as this contains the working version of the application.

## Code samples
As part of the project's requirements, there are screenshots of short programs written in the languages featured. The source code for each program is included in the repository and can be found in the folder "Code samples".
